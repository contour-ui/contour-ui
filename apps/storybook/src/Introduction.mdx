# contour-ui

Design system for audio-plugin UIs and general web UI. This Storybook composes
the per-package Storybooks:

- **Tokens** — design tokens (layer 0)
- **Headless** — unstyled behavior (layer 2)
- **React** — styled components (layer 3): **Essentials**, the everyday components, and
  **Audio**, the controls of audio-plugin UIs
- **Fumadocs** — the documentation layout for fumadocs-core sites, built from the styled
  components (layer 4)
