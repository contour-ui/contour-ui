# contour-ui

Design system for audio-plugin UIs and general web UI. This Storybook composes
the per-package Storybooks:

- **Tokens** — design tokens (layer 0)
- **Headless** — unstyled behavior (layer 2)
- **Kit** — styled general-purpose components (layer 3)
- **Audio** — styled audio components (layer 3)
- **Fumadocs** — the documentation layout for fumadocs-core sites, built from Kit (layer 4)
