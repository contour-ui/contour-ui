## Anatomy

| Part               | Element | Attributes                                  |
| ------------------ | ------- | ------------------------------------------- |
| `Placeholder.Root` | `div`   | `data-scope="placeholder" data-part="root"` |

`Placeholder.Root` accepts every `div` prop and renders no class or styles.
