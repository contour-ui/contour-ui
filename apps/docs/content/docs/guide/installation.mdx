## Requirements

- React 19 and React DOM 19: peer dependencies of every package.
- A bundler that imports CSS from packages: Vite, Next.js, Rsbuild, webpack with a CSS loader.
  The packages are ESM only.

## Install

Your app imports the token stylesheet (and, for Audio, the Kit stylesheet) directly, so list those
packages as your own dependencies too: strict package managers such as pnpm do not expose
dependencies of dependencies to your code. Pick your package manager in any block below: the
others follow, and the site remembers it.

**Kit:**

```package-install
@contour-ui/react @contour-ui/tokens
```

**Headless**, no styles and no tokens:

```package-install
@contour-ui/headless-react
```

**Fumadocs**, a docs site on fumadocs-core:

```package-install
@contour-ui/fumadocs @contour-ui/react @contour-ui/tokens fumadocs-core fumadocs-mdx
```

A docs site on Fumadocs takes a few more steps: [Setup](/docs/fumadocs/setup) wires it into React
Router or Next.js.

## Load the stylesheets

Kit styles its components with plain CSS that reads token variables. Import the
stylesheets once, in your app entry, in this order:

```tsx title="main.tsx"
import '@contour-ui/tokens/tokens.css'; // tokens: --ct-* custom properties for every theme
import '@contour-ui/tokens/fonts.css'; // IBM Plex Sans and JetBrains Mono
import '@contour-ui/react/styles.css';
```

The stylesheets do not import each other, so your app decides what loads and when, and tokens
load once.

`fonts.css` declares the font faces the type tokens refer to (SIL Open Font License). Skip it if
your app already provides these fonts; the token font stacks fall back to system fonts.

Headless needs no stylesheet. A docs site on Fumadocs loads `@contour-ui/fumadocs/styles.css`
after the tokens and before Kit's stylesheet, since its first rule sets the order of the cascade
layers ([Fumadocs](/docs/fumadocs#load-the-stylesheets)).

### Cascade layers

Every Kit rule sits in a
[cascade layer](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer): `contour.components`, inside
the `contour` layer. CSS outside any layer wins over layered CSS
whatever its selectors, so your own stylesheet overrides a component without heavier selectors or
`!important`:

```css title="app.css"
/* Wins over Kit's rule for the same class: same selector, but not in a layer. */
.contour-button {
  border-radius: 0;
}
```

- **Tokens.** `tokens.css` only defines custom properties on `:root`, outside any layer, so the
  layers do not affect it.

Resets count as your CSS too: a reset loaded outside a layer overrides the components as well.
Give it a layer declared before `contour`:

```css title="app.css"
@layer reset, contour;
@import './reset.css' layer(reset);
```

### With Tailwind CSS

Tailwind CSS v4 puts its CSS in four layers: `theme`, `base` (Preflight, its reset), `components`
and `utilities`. Layers rank in the order they are first declared, the last one strongest, so
declare the whole order once, at the top of the stylesheet that imports Tailwind:

```css title="app.css"
@layer theme, base, contour, components, utilities;
@import 'tailwindcss';
```

`contour` comes after `base`, so Preflight does not strip the components' padding, borders and
backgrounds, and before `utilities`, so a utility class overrides a component, as in
`<Button className="rounded-none">`. Without this line the order follows whichever
stylesheet loads first: if Kit's comes first, Preflight resets the components; if Tailwind's
does, utilities cannot override them.

## Page background

Tokens do not style the page itself. Give the document the canvas colors so the space around
components follows the theme:

```css title="app.css"
body {
  margin: 0;
  background: var(--ct-color-bg-canvas);
  color: var(--ct-color-fg-default);
  font: var(--ct-text-body);
  letter-spacing: var(--ct-text-body-letter-spacing);
}
```

## A minimal app

```tsx title="main.tsx"
import { Button } from '@contour-ui/react';
import { createRoot } from 'react-dom/client';

import '@contour-ui/tokens/tokens.css';
import '@contour-ui/tokens/fonts.css';
import '@contour-ui/react/styles.css';
import './app.css';

const root = document.querySelector('#root');
if (root !== null) {
  createRoot(root).render(<Button>Hello, contour-ui</Button>);
}
```
