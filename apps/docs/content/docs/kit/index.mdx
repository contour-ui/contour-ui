Kit is the styled layer for everyday UI. Its stylesheet is built on [tokens](/docs/guide/styling),
so every component follows the [theme](/docs/guide/themes) with no extra code. Components with
behavior, such as popovers and dialogs, are [Headless](/docs/headless) components plus that
stylesheet; components without behavior, such as buttons, cards and alerts, exist only in Kit.

## Setup

```bash
pnpm add @contour-ui/kit @contour-ui/tokens
```

```tsx title="main.tsx"
import '@contour-ui/tokens/tokens.css';
import '@contour-ui/tokens/fonts.css';
import '@contour-ui/kit/styles.css';
```

Details and the reasons for the order: [Installation](/docs/guide/installation).

## Usage

A component made of one element is a plain component, such as `Button`; a component with several
parts is a namespace of parts, such as `Card`. Each part renders one element and passes its props
through:

```tsx
import { Button, Card } from '@contour-ui/kit';

export function Welcome() {
  return (
    <Card.Root>
      <Card.Body>
        <Card.Title>Welcome</Card.Title>
        <Card.Description>Start with the guide.</Card.Description>
      </Card.Body>
      <Card.Footer>
        <Button>Open the guide</Button>
      </Card.Footer>
    </Card.Root>
  );
}
```

## Customizing

- **Classes.** Each component has a class, `contour-<component>`, and each of its other parts
  `contour-<component>__<part>`. Your `className` is added next to them, so you can extend the
  styles with your own CSS. Variants and sizes are attributes, as in
  `.contour-button[data-variant='ghost']`.
- **Tokens.** Write overrides with token variables, and they keep following the theme:

  ```css
  .status {
    padding: var(--ct-space-panel-inset);
  }
  ```

- **Another look.** If the Kit styles are in the way, use the same component from
  [Headless](/docs/headless): same parts, same props, no CSS. Components without behavior have no
  Headless version: build your own from `Primitive`, the elements every part renders through.
