Add `Clipboard`, on the clipboard of `@contour-ui/headless-react`: a value to copy, such as an install command, in a bordered row (`Clipboard.Control`) as high as a control of its size (`sm`, `md`, `lg`), with the value in mono on one line that ends in an ellipsis when the row is too narrow (`Clipboard.ValueText`, with an optional `prompt` such as `$` that CSS draws, out of the value, the selection and what screen readers read). `Clipboard.Trigger` is a Kit `Button`, `ghost` and muted by default, that fills the end of the row with its focus ring inside: a text button with children, a square icon button without. `Clipboard.Indicator` shows its children, or `copied` while the value is copied, by default a copy icon that turns into a check mark, and pops what it shows while copied in (a fade under reduced motion); it is hidden from assistive technology, since the trigger keeps its name ("Copy to clipboard") and a status element announces the copy. `Clipboard.Label` sits above the control and names the clipboard, a `group`.
