Add `@contour-ui/fumadocs`: a documentation layout for sites on `fumadocs-core`, built from `@contour-ui/react`, to install in place of `fumadocs-ui`. `DocsProvider` (site, search, theme), `docsScript()` (the theme and the collapsed sidebar before the first paint), `DocsLayout` (a collapsible sidebar with a section switcher and the page tree; a header with a menu drawer on phones), `DocsPage` (title, description, the table of contents as a column or a bar, the previous and next pages), `HomeLayout`, and the parts `SearchTrigger`, `ThemeToggle` and `SkipLink`; the search dialog on fumadocs-core's static index. `@contour-ui/fumadocs/mdx` gives `getMdxComponents()` (headings with anchors, links, tables, code blocks, callouts, cards, previews) and `Prose`; `@contour-ui/fumadocs/styles.css` sets the cascade layers. Links and navigation come from the app's framework adapter (`fumadocs-core/framework`): React Router, Next.js, TanStack and Waku. Client modules carry `'use client'`, so it works with React Server Components.
