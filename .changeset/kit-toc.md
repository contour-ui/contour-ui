Add `Toc`: the `Root`, `Title`, `List`, `Item`, `Link` and `Indicator` parts of the Headless table of contents, styled. Links are muted, and active or hovered ones take the default text color; the list draws a line along its start, over which the indicator, an accent bar, slides to the active items (without sliding when the user prefers reduced motion). Each level below an `h2` indents an item one step.
