Add `CodeBlock`: `Root` (a `figure`), `Header` (its `figcaption`), `Title` and `Content` frame code highlighted by Shiki with its css-variables theme. The root maps the `--shiki-*` variables to the syntax color tokens, so the code follows the color theme. `Content` scrolls long lines and is focusable, and styles Shiki's output: highlighted lines and words, added and removed lines, focused lines and line numbers.
