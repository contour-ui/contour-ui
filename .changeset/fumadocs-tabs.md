Add `Tabs` and `Tab` to the MDX components, with the props of Fumadocs (`items`, `defaultIndex`,
`label`, `groupId`, `persist`, `updateAnchor`), and draw the code block tabs that Fumadocs'
`remarkCodeTab` and `remarkNpm` write into a page: consecutive code blocks with a `tab` meta, and
the commands of each package manager for `npm` and `package-install` blocks.
