Add `Button`: the four variants and three sizes of the web `Button`, on Soundor's `Pressable`, drawn with the token values of the theme. Strings in its label take the `label` text style (`label-lg` in `lg`). Its focus ring is a view outside the border, shown when the button was focused from the keyboard, as `:focus-visible` does; a `style` function receives that state as `focusVisible`.
